# 生物医学图像生成的主要方法流派：文献研究综述

**检索与核查日期：2026-07-27**  
**范围：** MRI、CT、PET、X-ray、超声、组织病理等生物医学图像的合成、翻译、重建、异常/反事实生成；不把纯文本生成作为主体。  
**证据基础：** 49 篇核心文献（47 篇同行评审、2 篇预印本），其中 9 篇全文精读；另核查 4 个代码仓库。

## 摘要

按**概率模型的训练目标和生成机制**划分，生物医学图像生成主要有六条流派：

1. 自动编码器/变分自动编码器（AE/VAE）；
2. 生成对抗网络（GAN）；
3. 自回归与离散 token 模型；
4. 归一化流（normalizing flow）；
5. 扩散、score-based 与 flow matching/rectified flow；
6. 物理模型、解剖模拟器与神经生成器的混合路线。

若只求一个便于记忆的版本，可以说传统综述中的三大类是 **VAE、GAN、diffusion**；但严格的方法学分类不应漏掉自回归和 normalizing flow，也不应忽略医学成像中特别重要的物理/数据一致性混合方法 [@singh2021review; @kazerouni2023diffusion; @dayarathna2024deep]。截至 2026 年，**扩散/score/flow 是研究中心**，GAN 仍在快速图像翻译与纹理生成中有价值，VAE/VQ-GAN 常作为潜空间压缩器，自回归和 normalizing flow 是较小但独立的支线；决定临床可信度的关键正从“更逼真”转向“病灶忠实、三维一致、可控、可外部验证”。

## 1. 如何正确理解“流派”

“MRI→CT”“文本到胸片”“数据增强”“异常检测”是**任务**；VAE、GAN、扩散等是**生成机制**。两者不能混为一类。一个扩散模型既可做无条件合成，也可做重建、跨模态翻译和异常检测；同一个 MRI→CT 任务也可由 GAN、扩散或物理约束模型完成。

同理，“多模态模型”“基础模型”“文本条件模型”通常是规模、条件或系统架构层，而不是新的概率生成原理。RoentGen 与 MedM2G 等系统的底层仍是潜扩散或跨模态扩散 [@chambon2022roentgen; @zhan2024medm]。

## 2. 六条主要方法流派

| 流派 | 核心思想 | 优势 | 主要风险/代价 | 典型医学用途 |
|---|---|---|---|---|
| AE/VAE | 编码到潜变量，再解码重建；VAE 优化 ELBO | 稳定、潜空间连续、编码快 | 图像偏平滑，小病灶可能被重建损失抹去 | 正常解剖建模、异常检测、形变模板、潜空间压缩 |
| GAN | 生成器与判别器对抗 | 采样快、纹理锐、翻译成熟 | 训练不稳、模式坍塌、可能添加/删除病灶 | MRI↔CT、序列补全、虚拟染色、增强、超分辨 |
| 自回归/token | 按像素或离散 token 的顺序预测 | 显式条件概率、适合统一序列建模 | 串行采样慢，次序和 token 长度敏感 | VQ-VAE+Transformer、异常替换、多模态 token |
| Normalizing flow | 可逆变换连接简单分布与图像分布 | 精确似然、双向映射 | 架构受可逆性限制、内存高；高似然未必代表正常 | 异常评分、可逆翻译、VAE 后验 |
| Diffusion/score/flow | 从噪声逐步去噪，或学习连续概率输运向量场 | 覆盖性与稳定性较好、条件控制灵活、适合 3D | 训练/采样昂贵；潜压缩可能丢失细节；仍会幻觉 | 3D CT/MRI、文本条件、跨模态、异常、反事实 |
| 物理/模拟混合 | 生成先验与成像前向模型、解剖/生理约束联合 | 能解释原始测量，可信度潜力高 | 依赖准确的领域模型，模拟器偏差会传递 | MRI/CT/PET 重建、低剂量、数字人体、虚拟试验 |

### 2.1 AE/VAE：从独立生成器转为潜空间基础设施

VAE 通过变分下界学习连续潜空间 [@kingma2014auto]。医学影像中，常用健康数据训练 AE/VAE，再以重建残差定位异常 [@zimmerer2019context; @baur2021autoencoders]；也可学习条件解剖模板与形变 [@dalca2019learning]。其独立生成图像常较模糊，但 VQ-VAE/VQ-GAN 已成为两类强模型的前端：一类在离散 token 上训练 Transformer，另一类在低维潜空间中训练 diffusion [@oord2017neural; @rombach2022high]。因此 VAE 没有消失，而是“组件化”了。

### 2.2 GAN：奠定跨模态翻译，也最早暴露医学幻觉

pix2pix 与 CycleGAN 分别建立成对、非成对图像翻译范式 [@isola2017image; @zhu2017unpaired]。早期医学 GAN 已用于 3D MRI→CT、多对比度 MRI 和虚拟染色 [@nie2017medical; @wolterink2017deep; @dar2019image; @janowczyk2021generative]。

GAN 的问题不仅是训练不稳定。Cohen 等构造 MR→CT 实验，证明分布匹配损失会根据训练集统计关系添加或删除肿瘤，即使输出视觉上合理 [@cohen2018distribution]。这揭示了医学生成的核心矛盾：**整体分布逼真不等于患者级证据忠实**。GAN 因单步采样仍适合实时或高吞吐翻译，但临床应用必须加入结构、病灶或测量一致性约束。

### 2.3 自回归/token：概率清楚，但采样串行

PixelCNN 逐像素建模条件概率 [@oord2016conditional]；VQ-VAE 则先把图像变成离散 token，再用自回归模型或 Transformer 学习 token 分布 [@oord2017neural]。Pinaya 等在健康脑 MRI token 上训练 Transformer，用正常 token 替换异常区域；多排列集成使异常分割 Dice 从单独 VQ-VAE 的 0.457 提高到 0.895 [@pinaya2022unsupervised]。

它的优势是概率目标明确，也容易把图像、文本、标签统一为序列；缺点是高分辨率图像产生极长 token 序列，采样速度受限。它不是扩散的变体，而是一条独立且仍有潜力的路线。

### 2.4 Normalizing flow：精确似然的小众路线

Normalizing flow 通过可逆映射和变量替换公式计算精确似然，也可构造更灵活的 VAE 后验 [@rezende2015variational]。其价值在可逆性、密度估计和潜空间解释；但可逆结构限制网络设计，高维医学体数据计算/内存昂贵。更根本的问题是：生成模型有时会给分布外样本较高似然，所以“低似然就是病变”并不可靠。当前它更常作为潜变量、后验或重建组件。

### 2.5 Diffusion、score 与 flow：当前主导平台

DDPM 学习逐步加噪过程的逆过程 [@ho2020denoising]，score-based 方法用随机微分方程和概率流 ODE 统一这类模型 [@song2021score]。其在医学领域成为主流，主要因为训练相对稳定、模式覆盖较好、条件控制灵活，而且能自然延伸到三维体数据。

几个代表性结果说明了这种转向：

- Mueller-Franzes 等在 AIROGS、CRCMS、CheXpert 上报告扩散模型 FID 为 11.63、30.03、17.28，优于其 GAN 对照的 20.43、49.26、84.31 [@muellerfranzes2023diffusion]。
- Khader 等把 VQ-GAN 压缩与 3D DDPM 结合；阅片评价中，189/200 张图被认为逼真，191/200 具有切片一致性，185/200 解剖结构可信；在小数据分割设置中，合成增强使 Dice 从 0.91 提升到 0.95 [@khader2023denoising]。
- 脑 MRI 潜扩散已能按年龄、性别和脑结构体积条件生成，并用于构造大规模合成队列 [@pinaya2022brain]。
- MAISI 把潜扩散扩展到大体积 CT/MRI、可变体素间距、器官/肿瘤控制和图像—分割掩膜联合生成 [@guo2025maisi]。

这个家族内部也在演化。像素 diffusion 保真但昂贵；latent diffusion 先压缩再生成，高效但可能损失微小征象；DDIM 等减少步数；flow matching 直接学习连续向量场 [@lipman2023flow]。目前工程已出现从 1000 步 DDPM 转向约 30 步 rectified flow 的趋势。理论分类上，flow matching 可单列；为便于理解，本综述把它视为连续概率输运大家族中的新分支。

### 2.6 物理—生成混合：医学领域最重要的正交路线

MRI 有 k-space，CT/PET 有投影与重建算子，显微与病理有光学/染色过程。纯数据驱动模型只学“长得像”，物理混合模型则要求输出同时解释真实测量，或遵守解剖、拓扑与生理规律。这条路线可以使用 VAE、GAN、diffusion 或 flow 作为先验，所以它与前五类是正交关系。

在重建、低剂量成像、数字人体和虚拟临床试验中，这类方法最有希望减少不可实现图像；代价是必须面对前向模型和模拟器自身的系统偏差。

## 3. 当前前沿：从画得像转向受控且可验证

2025–2026 年的前沿可概括为五个方向：

1. **结构与拓扑一致性。** Noise-Consistent Siamese Diffusion 联合合成与分割；TopoCellGen 显式建模组织病理细胞拓扑，并提出 TopoFD [@qiu2025noise; @xu2025topocellgen]。
2. **少数据与中心适配。** MedDiff-FT 以结构引导进行数据高效微调，回应医学配对数据稀缺 [@xie2025meddiff]。
3. **统一多模态。** MedM2G 在同一框架中连接文本、X-ray、CT、MRI；文本条件 LDM 正从一对一转换走向一对多 [@zhan2024medm; @zhang2025high]。
4. **反事实和疾病进展。** Latent Drifting 与 xMADD 尝试沿潜空间轨迹生成疾病/时间条件图像 [@yeganeh2025latent; @friedman2026xmadd]。这类“可控”仍需纵向或干预数据证明因果有效。
5. **高速三维生成。** 大体积潜模型正采用 rectified flow 减少采样步数，同时加入图像—标签联合控制。

## 4. 方法选择建议

- **成对、实时图像翻译：** 先考虑条件 GAN；若病灶忠实性优先，加入强结构/数据一致性并与条件 diffusion 比较。
- **无配对翻译：** CycleGAN 类方法易用，但幻觉风险高；应优先使用可逆、结构保持或物理约束版本。
- **高质量无条件/条件合成：** 当前首选 latent diffusion 或 rectified flow；三维任务需验证压缩器是否保留微小病灶。
- **异常检测：** 小数据下 AE/VAE 是稳定基线；Transformer token 替换或 diffusion 健康反事实可提高表达力，但必须验证异常不会被简单重建。
- **精确密度/双向映射：** 可考虑 normalizing flow，但不要把似然直接解释为临床正常概率。
- **重建和低剂量成像：** 优先采用“生成先验 + 前向模型/数据一致性”的混合路线。
- **临床部署：** 方法名称不是决定因素；外部验证、病灶级忠实性、隐私、公平性和可追溯性更重要。

## 5. 评测与临床安全

不能用单一 FID 宣称“临床可用”。较完整的证据链应包括：

1. 分布质量：医学域特征上的 FID/KID、precision/recall 与覆盖度；
2. 配对保真：PSNR、SSIM、MAE、LPIPS；
3. 解剖结构：器官体积、表面距离、拓扑、跨切片/多序列一致性；
4. 临床效用：合成数据增强后的 Dice、AUC、检测灵敏度，并在独立外部队列测试；
5. 读片试验：盲法、多阅片者、按病种和亚群分层；
6. 安全：最近邻、成员/属性推断、罕见病覆盖、公平性和反事实合理性。

尤其要区分三件事：图像是否逼真、疾病证据是否忠实、合成数据是否改善真实世界任务。三者相关，但不能互相替代。

## 6. 仍待解决的核心问题

1. **病灶忠实性：** 生成器会不会添加、删除或改变微小征象？
2. **跨中心泛化：** 扫描仪、协议、染色批次和人群变化后是否仍有效？
3. **罕见病覆盖：** 最需要合成增强的长尾病变，是否恰好被模型遗忘？
4. **3D/4D 一致性：** 体数据、多序列、心动/呼吸和纵向变化如何联合建模？
5. **反事实因果性：** 改变标签后生成的变化，是疾病机制还是数据集相关性？
6. **隐私—效用—公平性：** 合成数据并非天然匿名，且隐私保护可能进一步损伤罕见病质量。
7. **物理可实现性：** 输出能否由真实设备与成像过程产生？
8. **可复现与监管：** 受控数据、旧依赖、高算力、模型版本和数据 provenance 如何审计？

## 7. 结论

生物医学图像生成的主流并非简单的“GAN 被 diffusion 淘汰”。更准确的结论是：

- VAE/VQ-GAN 负责学习和压缩潜空间；
- GAN 保留快速、锐利的翻译能力；
- 自回归模型承担离散 token 与显式序列概率建模；
- normalizing flow 提供可逆性和精确密度；
- diffusion/score/flow 成为高质量、可控、三维和多模态生成的中心平台；
- 物理、解剖、因果与测量一致性决定生成图像能否成为可信的医学证据。

未来真正有临床价值的工作，不会只优化“看起来像真的”，而会同时回答：**是否保留病人的关键病理、是否遵守成像与解剖规律、是否覆盖少数和罕见病例、是否在外部队列有效、是否可审计。**
