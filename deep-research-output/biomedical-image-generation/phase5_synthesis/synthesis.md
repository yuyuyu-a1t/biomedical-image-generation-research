# Phase 5 — 跨论文综合：生物医学图像生成的方法谱系

## 1. 分类结论

若按**生成概率模型的训练目标**分类，而不是按应用名称分类，生物医学图像生成可归纳为六条主线：

1. 自动编码器与变分自动编码器（AE/VAE）；
2. 生成对抗网络（GAN）；
3. 自回归与离散 token 模型；
4. 可逆归一化流（normalizing flow）；
5. 扩散、score-based 与连续流输运（包括 flow matching/rectified flow）；
6. 物理模型、解剖模拟器与神经生成器的混合方法。

前三类旧综述常被压缩成“AE、GAN、diffusion”三大类，但这样会遮蔽自回归模型的精确似然、normalizing flow 的可逆密度估计，以及物理/数据一致性约束在成像重建中的独特作用 [@singh2021review; @kazerouni2023diffusion; @dayarathna2024deep]。相反，“基础模型”“多模态”“文本到图像”更适合作为跨模型的条件与规模化层，而不是第七种生成原理 [@chambon2022roentgen; @zhan2024medm]。

## 2. 六条主线的机制与定位

| 方法家族 | 核心训练信号 | 优点 | 主要弱点 | 典型医学任务 | 当前定位 |
|---|---|---|---|---|---|
| AE/VAE | 重建损失 + 潜变量正则/ELBO | 训练稳定、潜空间连续、编码/重建快速 | 样本易模糊，似然假设和像素损失可能压平小病灶 | 异常检测、表征、模板与形变、潜空间压缩 | 仍是重要组件，常作为 LDM 的第一阶段 |
| GAN | 生成器—判别器极小极大博弈 | 单步采样、局部纹理锐利、图像翻译成熟 | 模式坍塌、训练不稳、缺乏显式似然，可能“幻觉”病灶 | MRI↔CT、虚拟染色、增强、超分辨 | 从主导地位转为高效翻译/混合模块 |
| 自回归/token | 按顺序最大化离散 token 条件似然 | 概率目标清楚，适合长程依赖与多模态 token 化 | 串行采样慢；次序敏感；高分辨率 token 很长 | VQ-VAE 后的脑异常检测、多模态统一建模 | 小众但概念上独立 |
| Normalizing flow | 可逆变换 + 精确对数似然 | 精确密度、双向映射、潜空间解释性 | 可逆架构受限、内存高；高似然不等于临床正常 | 异常评分、可逆翻译、后验建模 | 研究支线，常作为 VAE/贝叶斯组件 |
| Diffusion/score/flow | 去噪 score、概率流 ODE 或向量场匹配 | 覆盖性好、训练较稳、条件控制灵活、3D 与多模态扩展强 | 训练/采样昂贵，潜扩散受压缩器影响，仍会幻觉 | 无条件合成、跨模态、异常、文本条件、3D CT/MRI、反事实 | 2023–2026 年的主导前沿 |
| 物理/模拟混合 | 生成先验 + 成像前向模型/解剖规则/数据一致性 | 可将测量、剂量、几何与生理约束写进推理 | 依赖领域模型；模拟器偏差会传入输出 | MRI/CT/PET 重建、低剂量成像、数字人体/病变模拟 | 临床可信度最有潜力的正交路线 |

## 3. 历史转换不是“替代”，而是模块重组

### 3.1 VAE：从独立生成器变成潜空间基础设施

VAE 以变分下界训练连续潜变量 [@kingma2014auto]。在医学影像中，它适合学习“正常解剖”并通过重建残差做异常分割 [@zimmerer2019context; @baur2021autoencoders]，也适合条件形变模板 [@dalca2019learning]。其独立生成质量通常不如 GAN 或扩散锐利，但 VQ-VAE/VQ-GAN 已成为 token 自回归模型和潜扩散模型的压缩前端 [@oord2017neural; @rombach2022high]。因此，VAE 并未消失，而是从“最终图像生成器”转为“医学图像潜空间”。

### 3.2 GAN：建立了医学图像翻译范式，也暴露了幻觉风险

条件 GAN 与 CycleGAN 使成对和非成对图像翻译成为标准范式 [@isola2017image; @zhu2017unpaired]。早期医学工作已实现 3D MRI→CT、无配对 MR→CT、多对比度 MRI 合成和病理染色迁移 [@nie2017medical; @wolterink2017deep; @dar2019image; @janowczyk2021generative]。GAN 的优势是采样快、纹理锐，但 Cohen 等证明：分布匹配损失能在 MR→CT 中加入或删除肿瘤，即使整体图像看起来合理 [@cohen2018distribution]。这不是某一网络的偶然失败，而是“逼真”目标与“忠实保留病人证据”目标不一致的结构性风险。

### 3.3 自回归/token：用序列建模换来明确概率结构

PixelCNN 直接分解像素条件概率 [@oord2016conditional]；VQ-VAE 将图像转为离散 token，再由 Transformer/自回归先验建模 [@oord2017neural]。Pinaya 等在脑 MRI 中用 VQ-VAE + Transformer 学习健康 token 分布，再以异常 token 替换实现异常分割；多次排列集成使 Dice 从单纯 VQ-VAE 的 0.457 提升至 0.895 [@pinaya2022unsupervised]。该路线比扩散采样更受次序和序列长度限制，但对“图像—文本—标签统一 token 化”仍有理论吸引力。

### 3.4 Normalizing flow：精确似然并不自动带来临床异常性

Normalizing flow 通过可逆映射与变量替换公式得到精确密度，也可强化 VAE 后验 [@rezende2015variational]。它在医学领域适合可逆翻译与异常评分，但面临两个问题：高维可逆网络计算/内存昂贵；更重要的是，生成模型可能给分布外样本较高似然，因此“低似然 = 病变”并不总成立。这使 flow 更常作为潜变量、后验或重建模块，而不是当前的大规模医学图像主生成器。

### 3.5 扩散/score：成为主导，随后向潜空间、条件控制和连续流演化

DDPM 通过逐步加噪与学习逆去噪过程生成数据 [@ho2020denoising]，score-based 模型将其统一到随机微分方程与概率流 ODE [@song2021score]。医学扩散的兴起有三点实证支撑：

- 与 GAN 相比，扩散在多种医学数据上表现出更好的分布覆盖和图像质量；Mueller-Franzes 等在 AIROGS、CRCMS 和 CheXpert 上分别报告 FID 11.63、30.03、17.28，优于其 GAN 对照的 20.43、49.26、84.31 [@muellerfranzes2023diffusion]。
- 3D 潜扩散把 VQ-GAN 压缩与 DDPM 结合，可在多个约千例的数据集中生成体数据；阅片实验中，189/200 张图被评为逼真，191/200 具有切片一致性，185/200 解剖结构可信 [@khader2023denoising]。
- 潜扩散已从脑 MRI 扩展到跨模态、文本条件和整身体数据；MAISI 支持可变体积/分辨率与图像—分割对生成，MedM2G 统一文本、X-ray、CT、MRI 多流任务 [@pinaya2022brain; @guo2025maisi; @zhan2024medm]。

扩散内部也在分化：像素扩散保真但昂贵；潜扩散高效却可能丢失小病灶；DDIM/少步采样减轻时延；flow matching 直接学习连续向量场 [@lipman2023flow]，在 NVIDIA 的后续三维模型中已由 1000 步 DDPM 转向约 30 步 rectified flow。因二者共享“从简单分布连续运输到数据分布”的思想，本综述把 flow matching 作为扩散/score 大家族中的新分支，而在工程选型时将其单列。

### 3.6 物理—生成混合：不是单一网络，而是可信性约束路线

医学图像往往来自已知的投影、k-space、点扩散函数、剂量或组织光学过程。因此，生成先验可与成像前向算子、数据一致性、解剖形变模型和数字人体模拟器组合。它与以上五类概率模型正交：GAN、VAE、diffusion 或 flow 都可作为先验。该路线的核心价值不是让图“更像”，而是使生成结果同时解释原始测量或遵守解剖/生理约束；这在重建、低剂量合成和可用于虚拟临床试验的数据生成中尤其重要。

## 4. 任务分类与方法分类必须分开

同一生成器可服务多种任务，同一任务也可由不同生成器完成。建议用下列第二坐标轴描述论文：

1. 无条件或类别条件合成：用于数据增强、共享和压力测试；
2. 图像到图像翻译：MRI→CT、缺失序列补全、虚拟染色；
3. 重建与恢复：低剂量、欠采样、去噪、超分辨；
4. 异常检测：生成“健康对应物”后以残差定位病灶 [@schlegl2017unsupervised; @wolleb2022diffusion; @wyatt2022anoddpm]；
5. 反事实与纵向生成：控制疾病、年龄、病程或干预 [@yeganeh2025latent]；
6. 文本/报告条件生成与统一多模态：X-ray、CT、MRI、文本之间的双向生成 [@chambon2022roentgen; @zhan2024medm]；
7. 三维解剖、图像—标签联合生成：用于分割训练与罕见结构控制 [@guo2025maisi]；
8. 组织病理拓扑/染色生成：强调细胞空间关系或生化染色真实性 [@xu2025topocellgen; @ozcan2023deep]。

## 5. 2025–2026 前沿集中在“可控、可验证、可扩展”

- **结构一致性**：Noise-Consistent Siamese Diffusion 将生成与分割耦合；TopoCellGen 直接优化细胞拓扑，而非只追求纹理 [@qiu2025noise; @xu2025topocellgen]。
- **数据高效适配**：MedDiff-FT 用结构引导进行少数据微调，回应医学小样本与中心迁移 [@xie2025meddiff]。
- **一对多与统一跨模态**：文本条件 LDM 和 MedM2G 尝试用一个系统覆盖多种成像转换 [@zhang2025high; @zhan2024medm]。
- **反事实与纵向**：Latent Drifting 通过潜变量轨迹生成疾病/时间条件反事实；xMADD 进一步统一条件合成与疾病进展建模 [@yeganeh2025latent; @friedman2026xmadd]。xMADD 为 2026 年会议论文；若引用其最新扩展版本，应重新核查版本状态。
- **高速三维生成**：大体积潜扩散向 rectified flow 迁移，在减少采样步数的同时维持可控体素空间。

## 6. 综合判断

生物医学图像生成并不是“GAN 已死、diffusion 全面取代”的线性故事。更准确的图景是：

- GAN 保留在需要快速采样、配对翻译和锐利纹理的任务中；
- VAE/VQ-GAN 变成许多扩散和 token 模型的压缩层；
- 自回归模型适合离散化、多模态序列和显式似然，但受采样速度限制；
- normalizing flow 在可逆性和密度建模中保持小众价值；
- diffusion/score/flow 已成为高质量、可控和三维生成的中心平台；
- 物理、解剖、因果与测量一致性决定这些生成器能否从“逼真图片”走向“可信临床证据”。
