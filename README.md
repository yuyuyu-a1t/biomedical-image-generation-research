# Biomedical Image Generation Research and LUNA16 Demo

本仓库包含两个相互衔接的教学成果：

1. [生物医学图像生成文献综述](deep-research-output/biomedical-image-generation/phase6_report/report.md)：梳理 AE/VAE、GAN、自回归模型、Normalizing Flow 和 Diffusion 等主要生成建模路线。
2. [LUNA16 二维 CT 扩散生成实验](luna16_2d_ct_generation/README.md)：使用 subset0 的 89 个 CT，完成 64×64 baseline、128×128 improved experiment，以及 50/100/200-step DDIM 采样比较。

实验结果、复现命令、模型权重 SHA-256、数据放置方式和限制均记录在实验目录 README 中。

> 本仓库中的医学图像生成结果只用于课程教学和生成建模演示，未经放射科医生评价，不能用于临床诊断、治疗或决策。
